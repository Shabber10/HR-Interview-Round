# 🎯 HR Interview Questions & Answers Repository

A structured, battle-tested repository containing comprehensive HR interview questions, interviewer intents, sample answers using proven frameworks (**STAR**, **Present-Past-Future**, **SAR**), and reverse questions for candidates across three distinct career tiers.

---

## 📂 Repository Structure

| Level | File | Target Audience | Key Focus Areas |
| :--- | :--- | :--- | :--- |
| **Level 1** | [Level 1: Entry-Level](./Level_1_Entry_Level_HR_Questions.md) | Freshers, College Graduates, Junior Roles (0–2 Years) | Foundational soft skills, learning agility, communication, cultural alignment, stress handling, salary expectation handling for freshers. |
| **Level 2** | [Level 2: Mid-Level](./Level_2_Mid_Level_HR_Questions.md) | Mid-Level Engineers, Specialists (2–7 Years) | Proven execution, conflict resolution, mistake recovery, task prioritization, mentorship, adaptability, reason for leaving. |
| **Level 3** | [Level 3: Senior & Leadership](./Level_3_Senior_Leadership_HR_Questions.md) | Leads, Managers, Directors, Executives (7+ Years) | Strategic vision, servant leadership, performance management, cross-functional influence, crisis management, DEI, executive negotiations. |
| **Master** | [All-in-One Master Guide](./HR_Interview_Questions_and_Answers.md) | All Levels | Complete, single-document compilation of all levels, frameworks, and summary matrices. |

---

## 🌟 Key Frameworks Used

- **STAR Method**: Situation, Task, Action, Result
- **Present-Past-Future Model**: For structuring elevator pitches ("Tell me about yourself")
- **Context Over Control**: Modern leadership and empowerment principles
- **70-20-10 Model**: Strategic resource and roadmap balancing
